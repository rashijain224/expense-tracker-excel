# Personal Expense Tracker Dashboard (Excel)

## Overview

This project is an interactive Personal Expense Tracker Dashboard created in Microsoft Excel.
It helps users analyze spending habits, monitor savings, and track expenses across different categories and payment methods.

## Features

* Expense Tracking System
* Summary KPI Cards
* Category-wise Expense Analysis
* Total Savings Calculation
* Budget Monitoring
* Most Used Payment Method
* Interactive Charts & Visualizations
* Clean Dashboard Layout

## Tools & Skills Used

* Microsoft Excel
* Tables & Formatting
* SUM, AVERAGE, MAX, MIN Functions
* IF Functions
* Pivot Tables
* Charts & Graphs
* Data Cleaning
* Dashboard Design

## Dashboard Insights

The dashboard provides insights such as:

* Total Expenses
* Highest & Lowest Expense
* Savings Remaining
* Spending Distribution by Category
* Payment Method Analysis
